# 🛒 Sistema de Vendas com Desconto em Java

## 📌 Sobre o Projeto

Este projeto consiste no desenvolvimento de uma aplicação simples em Java para simular o registro de vendas de uma loja. O sistema permite informar o valor de uma venda, aplicar descontos em compras acima de R$ 500,00 e apresentar o valor total por meio de caixas de diálogo.

## 🚀 Funcionalidades

- Entrada do valor da venda.
- Verificação de vendas acima de R$ 500,00.
- Solicitação de percentual de desconto.
- Cálculo automático do valor final.
- Exibição do resultado em uma caixa de diálogo.

## 🛠️ Tecnologias Utilizadas

- **Java**
- **Java Swing**
- **JOptionPane**
